### Environment Context

#### XIQ Network Overview
- The XIQ network consists of wireless access points, client devices, and supporting infrastructure.
- Access points are distributed across various locations and serve multiple client devices.
- The network is monitored using ExtremeCloud IQ tools and telemetry.

#### Key Systems
- **ExtremeCloud IQ**: Primary platform for network monitoring and management.
- **Telemetry Tools**: Provide real-time data on network performance and device health.
- **Client Radio Reports**: Offer insights into client connectivity and radio resource usage.

#### Permissions
- Permissions for write changes and configuration pushes must be obtained from the interface channel.
- Read permissions are granted for monitoring and diagnostics.

#### Topology
- The network topology includes multiple layers of wireless access points, client devices, and backend systems.
- Devices are categorized by location, type, and function.

#### Facts
- Wireless issues can arise from interference, misconfigurations, or hardware failures.
- Client radio reports are critical for identifying connectivity patterns and resource allocation.
- Regular monitoring is essential for maintaining network health.
