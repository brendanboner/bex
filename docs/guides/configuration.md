# Configuration Reference

All configuration is via environment variables in `.env` (root of the repo). Run `make setup` to auto-generate secrets, or use `bex init` for the full wizard.

---

## Required Secrets

These must be set before any service will start.

| Variable | Example | Description |
|---|---|---|
| `POSTGRES_PASSWORD` | `strong-random-pw` | PostgreSQL password |
| `REDIS_PASSWORD` | `strong-random-pw` | Redis password |
| `JWT_SECRET` | `openssl rand -hex 32` | JWT signing secret (32+ chars) |
| `CREDENTIAL_VAULT_KEY` | `openssl rand -hex 32` | AES-256 key for credential encryption (64 hex chars) |
| `DATABASE_URL` | `postgresql://bclaw:pw@localhost:5432/bclaw` | Full Postgres connection string |

## LLM Providers

Set the variables for whichever provider you use. Others can be left blank.

### OpenAI
```bash
OPENAI_API_KEY=sk-...
# Default model used for new agents:
LLM_DEFAULT_PROVIDER=openai
LLM_DEFAULT_MODEL=gpt-4o
```

### Anthropic
```bash
ANTHROPIC_API_KEY=sk-ant-...
LLM_DEFAULT_PROVIDER=anthropic
LLM_DEFAULT_MODEL=claude-3-5-sonnet-20241022
```

### Azure OpenAI
```bash
AZURE_OPENAI_API_KEY=...
AZURE_OPENAI_ENDPOINT=https://your-resource.openai.azure.com
AZURE_OPENAI_RESOURCE_NAME=your-resource
AZURE_OPENAI_DEPLOYMENT=gpt-4o
LLM_DEFAULT_PROVIDER=azure-openai
LLM_DEFAULT_MODEL=gpt-4o
```

## Notification Channels

### Telegram (Recommended)

1. Create a bot via [@BotFather](https://t.me/BotFather) — copy the token
2. Start a conversation with your bot and send `/start`
3. Get your chat ID: `https://api.telegram.org/bot<TOKEN>/getUpdates`

```bash
TELEGRAM_BOT_TOKEN=123456:ABC-DEF...
TELEGRAM_DEFAULT_AGENT_ID=<cuid of default agent>  # set after bex init
BFORGE_BOT_API_KEY=<JWT token for the bot>          # auto-generated by bex init
DEFAULT_APPROVAL_CHANNEL=telegram
```

### Microsoft Teams
```bash
TEAMS_BOT_ID=<bot app ID from Azure>
TEAMS_BOT_PASSWORD=<bot app password>
TEAMS_DEFAULT_AGENT_ID=<cuid of agent>
DEFAULT_APPROVAL_CHANNEL=teams
```

### WhatsApp (via Twilio)
```bash
TWILIO_ACCOUNT_SID=AC...
TWILIO_AUTH_TOKEN=...
TWILIO_WHATSAPP_FROM=whatsapp:+14155238886
WHATSAPP_APPROVAL_TO=whatsapp:+1234567890
DEFAULT_APPROVAL_CHANNEL=whatsapp
```

## Skill Registry

```bash
# URL of the skill registry this instance should sync with
# Leave blank to use the local registry only
SKILL_REGISTRY_URL=http://localhost:5050

# Bearer token for publishing/deleting skills (registry admin)
REGISTRY_ADMIN_TOKEN=<strong-random-token>

# The registry checks this env var to authenticate admin operations
# Same token used by bex CLI for registry commands
```

## Approval Callbacks

For approval workflows to work, the API gateway must be publicly accessible (or accessible from your notification service).

```bash
# Public URL that Telegram/Teams/WhatsApp can POST approval decisions to
PERMISSION_GATEWAY_CALLBACK_URL=https://your-domain.com
```

For local development, use [ngrok](https://ngrok.com):
```bash
ngrok http 4000
# Copy the https URL → PERMISSION_GATEWAY_CALLBACK_URL
```

## Advanced

```bash
# BullMQ concurrency (parallel agent requests)
WORKER_CONCURRENCY=5

REACHABILITY_CACHE_TTL=300

TOOL_ROUTER_T1_CAP=25
TOOL_ROUTER_T2_CAP=20
TOOL_ROUTER_T3_CAP=10

SSH_EXEC_TIMEOUT=30000

```

## Generating Secrets

```bash
# Generate all required secrets at once
make setup

# Or manually:
openssl rand -hex 32   # JWT_SECRET, REDIS_PASSWORD
openssl rand -hex 32   # CREDENTIAL_VAULT_KEY (must be 64 hex chars = 32 bytes)
openssl rand -base64 32 # POSTGRES_PASSWORD
```
